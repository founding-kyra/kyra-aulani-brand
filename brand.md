# Kyra Aulani — Brand Guidelines

Brand Architect for Visionaries. Elegant, intimate, signature-driven. Every value here is copied from the Heartfelt Wellbeing brand audit page, the reference Kyra set for all branded work.

## Quick rules (read first)

1. Ground is `white` (#f5f3ef) or `espresso` (#390d03). Alternate them in full-bleed sections. Never pure #fff or #000.
2. Headlines: **High Cruiser**, always UPPERCASE. Never body or long passages.
3. Body: **Atkinson Hyperlegible**. All running text, labels, eyebrows, buttons.
4. Script: **Quick Signature**. Only for the "Kyra Aulani" name, "xoxo", and one short closing line. Never anywhere else.
5. Accent: `olive`. Emphasis on dark: `rose`.
6. Square corners everywhere (`radius-none`). No shadows. No gradients.
7. Every text pair must pass WCAG AA (4.5:1). Use the contrast table below.

## Layout patterns (from the audit page)

- **Cover:** full-height `espresso`, butterfly, olive eyebrow, cream display title, rose script subtitle, 4px olive bottom rule.
- **Section rail:** 380px `espresso` left column (ghost numeral + olive eyebrow + cream title) beside a `white` content column.
- **Split:** `white` half (eyebrow + big title + muted italic "current copy") beside an `espresso` half (cream paragraphs, rose `<em>`).
- **Fix box:** solid `olive` fill, espresso label at 60%, bold espresso line. The one thing to use.
- **Cards:** `white`, 1px `gray` outline, optional 3px top accent in `olive` or `espresso`.
- **Status lists:** ✓ = done (espresso disc / cream glyph); ! or △ = gap (olive).
- **Priority list:** huge faded numeral (espresso at 13%) + uppercase title + muted description.
- **Closing:** `espresso`, display lines in cream, script lines in rose, footer with butterfly + kyraaulani.art.
- Gutters: clamp(32px, 6vw, 80px). Section padding: clamp(64px, 8vw, 104px).

## Voice

- "Gritty-elegant." Earthy and gritty as undercurrent, not headline.
- More elegant, more selective. Less casual filler, sharper sentences.
- Direct. No fluff.
- Written for established, discerning clients.
- Pattern from the audit: short declaratives that name the thing ("Name the outcome. Show the proof."), then one script line that softens it, then "xoxo".
- Never invent claims, prices or testimonials. Mark missing data with a flag: "⚑ NEEDS MANUAL INPUT".

## Don'ts

- No rounded corners, drop shadows, gradients, or emoji decoration.
- No script for anything but the name, "xoxo", or one closing line.
- No High Cruiser for body or long passages.
- No pure white or pure black.
- Don't use the retired Founding Mothers Media palette (mud, rust, maroon) or fonts (Coconat, Highway Gothic Condensed).
