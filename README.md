# Kyra Aulani — Brand System

The single source of truth for Kyra Aulani branded work: proposals, audits, pages, decks.

**Live guidelines:** https://founding-kyra.github.io/kyra-aulani-brand/

## What's here

| File | Use it for |
|---|---|
| `brand.md` | The rules. Paste or attach this into Claude, ChatGPT or any AI before asking for branded work. |
| `tokens.css` | Drop into any site or HTML file: colors, fonts, spacing as CSS variables. |
| `tokens.json` | Same tokens as data, for tools and code. |
| `components.css` | Ready-made classes (`ka-`) for cards, fix boxes, status lists, priority lists, offer cards, sign-off. |
| `logos/` | Logo files. |
| `fonts/` | Font notes (licensed files go here). |
| `index.html` | The visual guidelines page (GitHub Pages). |

## Use it

- **Claude:** "Use my Kyra Aulani design system" (lives in Claude as a Design System).
- **ChatGPT or any other AI:** attach `brand.md`, or paste its raw link.
- **Code:** `<link rel="stylesheet" href="https://founding-kyra.github.io/kyra-aulani-brand/tokens.css">`

## Edit it

Change a value in `tokens.json` **and** `tokens.css`, and the matching line in `brand.md`. Keep all three in sync.
